## Para que serve

Em **Documentos** você encontra os arquivos que a empresa compartilhou com você: manuais e políticas para todos, documentos do seu departamento e documentos pessoais, como o informe de rendimentos.

## Quando usar

Para consultar um manual, uma política ou baixar um documento pessoal enviado pelo RH.

## Passo a passo

1. No menu, em **Comunicação**, clique em **Documentos**.
2. Veja a lista. Cada documento mostra o título, o nome do arquivo, o tamanho, quem enviou e a data. A etiqueta ao lado do título indica para quem ele é:
   - **Geral**: para todos da empresa;
   - **Meu departamento**: para o seu departamento;
   - **Para mim**: só para você.
3. Para ver o documento sem baixar, clique no ícone de olho. PDFs e imagens abrem numa janela, com o botão **Baixar** no topo.
4. Para baixar direto, clique no ícone de download, à direita.

Atenção: se o download falhar, a tela pode não avisar. O arquivo é salvo com o nome do documento, mas não abre. Se o arquivo baixado não abrir, tente baixar de novo e, se continuar assim, avise o RH.

![Tela Documentos com dois documentos gerais, um do departamento e um pessoal, cada um com os ícones de visualizar e baixar](/capturas/meus-documentos.webp)

## O que acontece depois

O arquivo baixado vai para a pasta de downloads do seu navegador, com o nome original.

## Dúvidas comuns

**Apareceu "Visualização não disponível para este tipo de arquivo".** Só PDFs e imagens abrem na janela. Clique em **Baixar arquivo** para abrir o documento no seu computador.

**Apareceu "Erro ao baixar documento".** O arquivo não pôde ser baixado agora. Tente de novo e, se o erro continuar, avise o RH.

**A tela mostra "Nenhum documento disponível para você".** Ainda não há documento compartilhado com você, com o seu departamento ou com a empresa toda.

**Outras pessoas veem os meus documentos?** Os documentos com a etiqueta **Para mim** aparecem só para você nesta tela.
